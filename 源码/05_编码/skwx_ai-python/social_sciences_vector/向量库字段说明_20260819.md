# 向量库字段说明

本文档依据当前代码 [field.py](./national_development/field.py) 整理。新建集合共 58 个字段，向量维度为 768，使用 `COSINE` 相似度检索。

## 基础与向量字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | VARCHAR(255)，主键 | 向量记录唯一 ID |
| `title` | VARCHAR(255) | 图书名称 |
| `embedding` | FLOAT_VECTOR(768) | 正文切片生成的向量；当前语义检索只匹配此字段 |
| `book_id` | VARCHAR(255) | 图书 ID |
| `directory_id` | VARCHAR(255) | 章节/目录 ID |
| `text` | VARCHAR(65535) | 当前正文切片文本 |
| `literature_id` | VARCHAR(255) | 文献 ID |

## 新增筛选与切片字段

以下 6 个字段仅新结构集合具备，例如 `book_vector_v2`、`book_partition_7` 及后续新集合。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `publish_direct` | ARRAY<VARCHAR(255)> | 出版方向/分类值，最多 50 个；可用于 `ARRAY_CONTAINS` 筛选 |
| `chunk_index` | INT64 | 当前切片序号，从 0 开始 |
| `chunk_total` | INT64 | 原段落切分后的总片数 |
| `chunk_start` | INT64 | 当前切片在原文本中的起始位置 |
| `chunk_end` | INT64 | 当前切片在原文本中的结束位置 |
| `chunk_strategy` | VARCHAR(255) | 切片策略，例如 `paragraph_sentence_overlap_v2` |

## 当前检索逻辑

- 语义匹配：只比较 `embedding` 字段。
- 向量生成内容：当前由 `text` 对应的正文切片生成。
- 返回展示：通常返回 `id`、`title`、`text`、`book_id`、`directory_id`、`literature_id`、`directory_type`、`directory_name`。
- 标量筛选：可对集合实际存在的字段做 `=`、`like`、`in`、数组包含等条件筛选。
- `directory_en_search_title`、`en_search_title`、`author_name` 等是元数据字段，当前不参与 `embedding` 的语义匹配。

## 字段命名注意

当前 schema 使用下划线命名，不存在以下驼峰/嵌套字段：

```text
abstractEN
authorInfo.enName
enSearchTitle
```

对应的已有字段为：

```text
directory_en_search_title
en_search_title
author_name
```

## 新旧集合兼容性

历史旧集合通常为 53 字段结构，缺少上述 6 个新增筛选与切片字段。因此向旧集合发送 `publish_direct` 条件会报字段不存在错误。

生产检索应按集合 schema 处理条件：集合有字段则应用条件，集合无字段则忽略该字段条件并保留其他可用条件。旧集合的实际字段仍应以生产 Milvus schema 查询结果为准。
